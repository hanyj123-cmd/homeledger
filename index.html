    Troubleshooting (안 될 때)
    • redirect_uri / origin 오류: Google Cloud 클라이언트의 "승인된 JavaScript 원본"이 https://hanyj123-cmd.github.io 인지 확인하세요. (끝에 / 나 경로 없이)
    • access_denied / 앱이 확인되지 않음: OAuth 동의 화면에서 본인 계정을 테스트 사용자로 추가했는지 확인하세요.
    • 403 권한 없음: 로그인한 구글 계정에 시트가 공유되어 있어야 합니다.
    • Sheets API 미사용: Google Cloud 라이브러리에서 Google Sheets API를 "사용" 상태로 바꾸세요.
    • 탭이 부족함: 시트의 Apps Script에서 setupSheets를 다시 실행하세요.
